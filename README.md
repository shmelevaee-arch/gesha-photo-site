# Сайт фотографа Евгении Досаевой

Портфолио-сайт фотографа (Москва). Instagram: [@gesha__ph](https://www.instagram.com/gesha__ph/)

## Что это

Одностраничный сайт-портфолио по образцу Framer-шаблона «Objective»: тёмная тема,
крупная типографика, полноэкранные фото. Главное отличие от прототипа — навигация
сделана нумерованной табличкой-списком (01 / 02 / 03 …), а не строкой меню.

## Стек

HTML + CSS + JS без сборщика и фреймворков. Никаких зависимостей на рантайме —
папку можно открыть локально или отдать на статический хостинг как есть.

Python 3.12 + Pillow используются только на этапе подготовки: скачать фото
с Яндекс.Диска и сжать их под веб (скрипты в `_tools/`).

## Как запустить

```
python -m http.server 8000
```

Открыть http://localhost:8000

## Структура

```
index.html          — главная (меню-табличка)
lovestory.html      — галерея «Лавстори»
family.html         — галерея «Семья»
personal.html       — галерея «Персональные»
prices.html         — цены
assets/css/         — стили
assets/js/          — скрипты (лайтбокс, меню)
images/             — сжатые фото для веба (в репозитории)
_raw/               — оригиналы с Яндекс.Диска (НЕ в репозитории)
_tools/             — скрипты подготовки фото
```

## Подготовка фото (порядок важен)

```
python _tools/download.py   # скачать оригиналы с Яндекс.Диска в _raw/
python _tools/optimize.py   # сжать в images/ и создать manifest.json
python _tools/layout.py     # посчитать тон/крупность плана и выстроить композицию
python _tools/build_pages.py # пересобрать html из общего каркаса
```

`layout.py` обязателен после `optimize.py`: тот пересоздаёт манифест и сбрасывает
порядок кадров на алфавитный.
