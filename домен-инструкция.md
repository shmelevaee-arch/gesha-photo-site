# Подключение домена geshaph.ru к сайту

Домен куплен на аккаунте Евгении (reg.ru, заказ №220435853). Сайт лежит на GitHub Pages
в репозитории `shmelevaee-arch/gesha-photo-site`, файл `CNAME` с доменом уже в репозитории.

## Что делает Евгения в reg.ru

1. Войти на reg.ru → «Домены и услуги» → выбрать **geshaph.ru**.
2. Открыть «Управление зоной» (она же «DNS-записи»).
3. Удалить запись типа **A** со значением `95.163.244.138` — это парковка reg.ru.
4. Добавить пять записей:

```
A      @      185.199.108.153
A      @      185.199.109.153
A      @      185.199.110.153
A      @      185.199.111.153
CNAME  www    shmelevaee-arch.github.io.
```

Четыре адреса подряд — так и надо, у GitHub четыре сервера. Точка в конце `github.io.` обязательна.
Серверы имён (NS) не трогать.

## Что делаю я после этого

5. В настройках репозитория → Pages → Custom domain вписать `geshaph.ru`, сохранить.
6. Когда GitHub выпустит сертификат (10–60 минут) — включить галочку «Enforce HTTPS».
7. Проверить, что сайт открывается по https://geshaph.ru и по https://www.geshaph.ru.

## Как проверить, что записи дошли

```
curl -s "https://dns.google/resolve?name=geshaph.ru&type=A"
```

В ответе должны быть адреса 185.199.108–111.153 вместо 95.163.244.138.
Обновление DNS занимает от 15 минут до нескольких часов.
