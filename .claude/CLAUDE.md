# Проект: сайт фотографа Евгении Досаевой

Статический сайт-портфолио. Стек: HTML/CSS/JS без сборщика. Хостинг: GitHub Pages.

## Память проекта

Папки `memory/` в проекте нет — её роль играют два файла в корне:

- `индекс.md` — каталог-указатель: что есть в проекте, ключевые решения, структура.
- `журнал.md` — операционный лог: что сделал → зачем → результат. Дописывается по ходу работы.

Баги и их решения — не сюда, а в кросс-проектный `C:\Users\shmel\.claude\SOLVED-PROBLEMS.md`.

## Как проверять этот проект

- Локальный сервер: `python -m http.server 8000` в корне, открывать http://localhost:8000
- Проверка в браузере после каждого блока вёрстки: консоль на ошибки, сеть на битые картинки.
- Раскладка проверяется на 1280px (десктоп) и 375px (мобильный).
- После сжатия фото — контроль веса страницы галереи (цель: до ~3 МБ на экран).
